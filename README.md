# Student Grade Management using MongoDB

## Aim
To implement a Node.js application that connects with MongoDB and performs student grade aggregation.

## Description
This experiment demonstrates storing student records in MongoDB and calculating total, average, highest, and lowest marks using aggregation.

## Technologies Used
- Node.js
- MongoDB
- MongoDB Compass

## Operations
- Connect to MongoDB
- Store student records
- Calculate total marks
- Calculate average marks
- Find highest and lowest marks
- Sort students by average marks

## How to Run

```bash
npm install
node app.js
